StartPro 1.2.1 · 版本选择页按 PCL2 直接重做

这版不再保留自定义的“版本选择”样式，按 PCL2 2.13.1.1 的页面结构与源码逻辑移植成：

1. 独立整页：蓝色标题栏 + 返回箭头 + “版本选择”，隐藏启动器的五栏顶部导航。
2. 左侧文件夹列表：当前文件夹名称蓝色高亮；默认目录显示“官方启动器文件夹”，自定义目录显示父文件夹名。
3. 右侧分组卡片：标题带数量，例如“Forge 版本 (1)”“常规版本 (2)”“不常用版本 (3)”；不常用、愚人节、其他默认折叠。
4. 版本条目只保留名称、加载器/类型和基础版本，不再显示发布时间；选中版本不再加蓝色“当前”标签。
5. 收藏夹：鼠标移到版本行出现收藏、删除、设置三个按钮；收藏后的版本单独进入“收藏夹”卡片，并从原分组移除。
6. 文件夹操作改为 PCL2 的右键菜单：打开文件夹、刷新版本列表、移出列表；移出只删记录，不删磁盘文件。
7. 空文件夹显示“无可用版本”和“下载游戏”按钮。
8. 版本选择页隐藏 SPL 小助手悬浮球，避免遮挡 PCL2 风格卡片。
9. 关于与鸣谢页首位加入 PCL2 作者龙腾猫跃、项目地址与赞助链接；README 与 THIRD_PARTY_NOTICES.md 同步加入许可说明。

版本仍按 PCL2 逻辑分组：可安装 Mod / Forge / Fabric / NeoForge、收藏夹、常规版本、不常用版本、愚人节版本、整合包、其他版本；常规版本按 Drop 只留最新，快照只在整体最新时进入常规版本。

说明：页面结构、分组规则与交互按 PCL2 公开源码移植，但 StartPro 使用 Electron/JavaScript，不能直接运行 PCL2 的 VB.NET/WPF 源码。PCL2 版权归龙腾猫跃，以《PCL 分发有限许可》发布；本项目保留署名，若直接复制其大部分源码，需按该许可“重度使用”条款另行处理名称、关于页、源码公开与正版购买劝导。

这是预览包，版本号仍为 1.2.1，未发布到 GitHub Release。
