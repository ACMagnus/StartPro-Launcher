为什么首次打开没有版本？+

新安装默认使用 %APPDATA%\StartPro Launcher\game 这个空目录，不会自动接管你已有的 .minecraft 版本。需要玩原有版本时，到“设置 → 游戏 → 游戏目录”切换到你的 .minecraft 即可。

需要自己安装 Java 吗？+

启动器会自动扫描本机 Java。没有合适版本时，可以在“设置 → 游戏 → Java 管理”里下载 Temurin 8 / 17 / 21；也可以手动指定 javaw.exe 路径。

为什么 Windows 提示“未知发布者”？+

当前构建没有购买商业代码签名证书。请先核对页面上的 SHA-256，确认文件一致后，在 SmartScreen 中选择“更多信息 → 仍要运行”。

支持正版账号和离线账号吗？+

支持微软正版登录，也支持离线账号。离线账号只适合本地单人游戏；账号信息保存在本机配置目录，不会上传到第三方服务器。

下载慢怎么办？+

1.1.3 起，客户端 jar 和大型依赖库会按 Range 分 4–6 段并发下载，依赖库与资源文件也提高了并发。实际速度仍取决于你的宽带和当前镜像源；可以在“设置 → 启动器”切换下载源后重试。

能自动更新吗？+

可以检查更新、下载新包并做 SHA-256 校验；但不会替换正在运行的程序。下载完成后请关闭启动器，手动解压覆盖，或按提示替换。

支持 macOS / Linux 吗？+

当前官方构建只提供 Windows x64 包。源码可以在其他平台自行安装依赖并运行，但尚未提供官方 macOS / Linux 安装包。

和 Mojang / PCL2 官方是什么关系？+

StartPro Launcher 是独立项目，与 Mojang Studios、Microsoft 及 PCL2 作者没有关联，也不包含 PCL2 的代码或素材。Minecraft 是 Mojang Studios 的商标，请使用正版游戏。
