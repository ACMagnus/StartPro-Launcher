为什么首次打开没有版本？+

新安装默认使用 %APPDATA%\StartPro Launcher\game 这个空目录，不会自动接管你已有的 .minecraft 版本。需要玩原有版本时，到“设置 → 游戏 → 游戏目录”切换到你的 .minecraft 即可。

需要自己安装 Java 吗？+

启动时会自动寻找本机已有 Java：PATH、JAVA_HOME、Windows 注册表、常见 JDK 目录、官方启动器 runtime，以及 PCL / HMCL / Prism 等启动器自带 Java；自动选最高版本。启动具体版本时再按需要的 Java 大版本匹配，缺失才提示安装 Temurin 8 / 17 / 21。

为什么 Windows 提示“未知发布者”？+

当前构建没有购买商业代码签名证书。请先核对页面上的 SHA-256，确认文件一致后，在 SmartScreen 中选择“更多信息 → 仍要运行”。

支持正版账号和离线账号吗？+

支持微软正版登录，也支持离线账号。离线账号只适合本地单人游戏；账号信息保存在本机配置目录，不会上传到第三方服务器。

下载慢怎么办？+

1.1.3 起，客户端 jar 和大型依赖库会按 Range 分 4–8 段并发下载，依赖库与资源文件也提高了并发。实际速度仍取决于你的宽带和当前镜像源；可以在“设置 → 启动器”切换下载源后重试。

能自动更新吗？+

可以。Windows 完整包启动约 5 秒后自动检查更新；点“立即更新并重启”会下载完整包、校验 SHA-256，退出旧进程后替换程序文件并重新打开。更新只替换程序目录，不碰 %APPDATA% 里的配置和存档。也可以在“更多 → 检查更新”手动触发。

支持 macOS / Linux 吗？+

当前官方构建只提供 Windows x64 包。源码可以在其他平台自行安装依赖并运行，但尚未提供官方 macOS / Linux 安装包。

和 Mojang / PCL2 官方是什么关系？+

StartPro Launcher 是独立项目，与 Mojang Studios、Microsoft 及 PCL2 作者没有关联。版本选择页参考 PCL2 公开源码重制，PCL2 版权归龙腾猫跃；关于页已署名并链接 PCL2 项目与赞助页，按《PCL 分发有限许可》说明第三方关系。Minecraft 是 Mojang Studios 的商标，请使用正版游戏。
